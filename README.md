# Flow Studio

Mermaid 코드를 직접 편집할 수 있는 로컬 흐름도 편집기입니다.
ComfyUI의 노드 편집 방식과 Archify의 남색 캔버스·색상 체계를 참고하여 독립적으로 구현했습니다.

[MIT 라이선스](LICENSE) · [출처 및 사용 라이브러리](CREDITS.md) · [GitHub 게시 안내](GITHUB.md)

## 바로 실행

[Flow-Studio.html](Flow-Studio.html)을 다운로드한 뒤 Chrome, Edge 또는 Safari에서 열면 됩니다.
GitHub 파일 화면에서는 **Download raw file** 버튼으로 내려받을 수 있습니다.
설치, 로그인, API 키, 인터넷 연결이 필요하지 않습니다.
브라우저 자동 저장 외에 **저장** 버튼으로 프로젝트를 파일로 내려받아 보관하세요.
자동 저장은 브라우저와 파일 위치에 따라 별개로 유지됩니다.
[서브그래프 연결 예제](examples/subgraph-connections.flow.json)를 내려받아 **불러오기**로 열 수 있습니다.

## 사용법

1. **Mermaid 붙여넣기** → 코드를 입력 → **캔버스로 가져오기**.
2. 노드 위쪽의 작은 유형 표시 영역을 드래그하면 이동합니다. 이름을 클릭하면 바로 편집할 수 있습니다.
3. 왼쪽 목록에서 노드를 선택하면 오른쪽에서 이름·색·유형·소속 그룹을 바꿀 수 있습니다.
4. 노드의 **오른쪽·아래쪽은 출력**, **왼쪽·위쪽은 입력**입니다. 출력에서 다른 노드의 입력으로 끌어 연결합니다. 아래→위, 오른쪽→위, 아래→왼쪽 연결도 가능하며, 선택한 연결 방향은 저장·불러오기와 복사·붙여넣기 후에도 유지됩니다. 오른쪽 속성의 **다른 노드로 연결** 메뉴도 사용할 수 있습니다.
5. Shift+클릭 또는 왼쪽 체크박스로 여러 항목을 선택한 뒤 **그룹화**합니다. 같은 부모 그룹의 항목들을 묶을 수 있으며 그룹 안에 그룹을 만들 수도 있습니다.
6. 일반 그룹은 제목 옆 화살표로 접고 펼칩니다. **서브그래프로 변환**하면 하나의 카드가 됩니다. 기존 선이 선택 영역의 안팎을 오가는 실제 노드에 입력·출력 연결점을 만들며, 내부 연결과 분기를 유지합니다. 외부 연결이 없다면 **입력·출력 편집**에서 원하는 노드를 연결점으로 노출할 수 있습니다.
7. 서브그래프의 **내부 편집** 버튼 또는 제목 두 번 클릭으로 내부 캔버스를 엽니다. 상단 경로나 **Esc**로 상위 화면으로 돌아옵니다. 내부에 서브그래프를 중첩할 수 있습니다.
8. 서브그래프 카드의 연결점을 **바깥 노드와 연결하면 내부 화면에 같은 연결이 자동 반영**됩니다. 내부 입력·출력 카드는 외부 연결 상태를 보여줍니다. **입력·출력** 설정에서는 노출할 연결점과 이름·대상 노드를 지정합니다. 슬롯 삭제 시 해당 외부 연결과 이에 의존하는 상위 슬롯도 해제되며 되돌릴 수 있습니다.
   각 입력 슬롯은 카드의 왼쪽과 위쪽, 출력 슬롯은 오른쪽과 아래쪽에서 연결할 수 있습니다. 위·아래 연결점에 마우스를 올리면 슬롯 이름이 표시됩니다.
9. **입력·출력 편집 → 바깥 카드 설정**에서 내부 노드의 이름·색상·유형을 노출할 수 있습니다. 바깥 카드에서 값을 바꾸면 원래 내부 노드에 반영되며, 내부에서 수정한 값도 바깥 카드에 표시됩니다.
10. **저장**은 `.flow.json` 파일을 다운로드합니다. **불러오기**로 이름·색상·위치·그룹·서브그래프와 연결점·노출 설정 정보를 복원합니다.

예를 들어 `이미지 로드 → VAE 인코드`, `이미지 로드 → 미리보기`에서 앞의 두 노드를 서브그래프로 만들면, 내부의 `이미지 로드 → VAE 인코드`는 유지됩니다. 바깥의 미리보기로 이어지는 출력은 **이미지 로드**에 연결됩니다. 마지막 노드인 VAE 인코드로 바뀌지 않습니다.
이전 버전에 저장된 연결점 설정은 유지됩니다. 과거에 자동으로 추가된 연결점까지 다시 구성하려면 서브그래프를 풀고 다시 변환하세요.

노드·그룹·연결선·빈 캔버스에서 **마우스 오른쪽 버튼**을 누르면 해당 항목의 편집 메뉴가 열립니다.
이미 선택한 노드를 우클릭하면 다중 선택을 유지합니다.
노드 메뉴에서 이름·색·유형 변경, **복사·붙여넣기·복제**, 그룹화·해제, **서브그래프로 변환**, 삭제를 실행할 수 있습니다.
기존 그룹을 변환하면 중첩 그룹을 추가하지 않고 서브그래프 카드로 바꾸며 내부 노드·연결·위치는 보존됩니다.
**서브그래프 풀기**는 내부 항목을 현재 화면으로 꺼내고 내부·외부 연결을 유지합니다.

복제와 복사·붙여넣기는 선택한 노드, 그룹의 모든 내부 항목, 내부 연결을 함께 복사합니다.
서브그래프의 입력·출력과 바깥 카드 설정도 보존하며 복사본은 원본과 독립적으로 편집됩니다.
선택 밖의 노드로 이어지는 연결은 복사하지 않습니다. 다른 서브그래프 안으로도 붙여넣을 수 있습니다.
텍스트를 편집할 때는 기본 텍스트 복사·붙여넣기가 동작합니다.

**⌘G / Ctrl+G는 그룹화와 해제를 전환합니다.** 그룹화한 직후 같은 선택에서 다시 누르면
그룹이 해제되고 내부 항목이 선택됩니다. 텍스트 입력 중에는 실행되지 않습니다.
터치 화면에서는 도구 막대의 **선택 작업 메뉴(···)**를 사용할 수 있습니다.

연결선을 클릭하거나 선 위에서 드래그하면 선이 선택됩니다. **Backspace / Delete**로 선택한 선을 지우며, Shift+클릭으로 여러 선을 선택할 수 있습니다. 서브그래프 안팎의 선은 같은 연결이므로 어느 화면에서 삭제해도 함께 반영됩니다. 연결 이름, 점선, 화살표는 오른쪽 속성에서 편집합니다.
**노드 추가**는 기존 카드와 겹치지 않는 가까운 빈자리에 새 노드를 배치하고 해당 위치로 화면을 이동합니다.
그룹 해제는 내부 노드를 남깁니다. 그룹 삭제는 내부 노드도 삭제하며 되돌릴 수 있습니다.

| 조작 | 동작 |
|---|---|
| Space + 드래그 / 가운데 버튼 드래그 | 캔버스 이동 |
| 휠 / 트랙패드 확대 | 확대·축소 |
| 빈 공간 드래그 / Shift+클릭 | 여러 노드 선택 |
| 왼쪽 목록 이름 클릭 | 해당 노드 또는 그룹으로 화면 이동 |
| Cmd/Ctrl+Z | 되돌리기 |
| Cmd/Ctrl+Shift+Z | 다시 실행 |
| Cmd/Ctrl+S | 파일 저장 |
| Cmd/Ctrl+G | 그룹화 / 선택된 그룹 해제 |
| Cmd/Ctrl+C | 선택한 노드·그룹·서브그래프 복사 |
| Cmd/Ctrl+V | 현재 캔버스에 붙여넣기 |
| Esc | 서브그래프에서 한 단계 위로 이동 |
| 마우스 오른쪽 버튼 | 대상의 편집 메뉴 |
| Shift+F10 | 캔버스에서 선택 항목의 편집 메뉴 |
| 메뉴에서 ↑/↓, Home/End | 메뉴 항목 이동 |
| 메뉴에서 →/←, Esc | 하위 메뉴 열기/돌아가기, 메뉴 닫기 |
| Cmd/Ctrl+A | 현재 편집 화면의 항목 선택 |
| Delete / Backspace | 선택 항목 삭제 |

## Mermaid 지원 범위

- `flowchart`와 `graph`, TD/TB/BT/LR/RL 방향.
- 한글 노드 이름, 연결 이름, 분기, 반복 연결, 중첩 `subgraph`.
- 사각형 계열은 프로세스, 다이아몬드는 조건/분기, 둥근 계열은 시작/종료 유형으로 변환.
- 직접 지정한 3/6자리 HEX `fill` 색상, 점선, 화살표 유무를 가져옵니다.
- 원본의 모든 도형·CSS·아이콘·클릭 동작을 그대로 재현하지 않습니다. 다른 종류의 Mermaid 다이어그램은 지원하지 않습니다.
- 저장 형식은 편집 정보를 보존하는 Flow Studio JSON입니다. Mermaid 코드로 다시 내보내는 기능은 포함하지 않습니다.

코드 입력 한도는 100,000자, 프로젝트 한도는 노드/그룹 1,000개와 연결 5,000개입니다.
복잡한 그래프에서는 자동 정렬 이후 위치와 겹치는 연결을 직접 조정할 수 있습니다.

## 개발

Node.js 22 이상과 pnpm을 사용합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build
```

빌드 결과 `dist/index.html`은 모든 실행 코드를 포함한 단일 HTML입니다.
개발 중에만 React Grab/Scan 도구가 로드되며 배포 파일에는 포함되지 않습니다.

구조: `model.ts` 파일 검증, `graph.ts` 그룹과 화면 투영, `layout.ts` 계층 정렬,
`mermaid.ts` 가져오기, `useDocument.ts` 저장·변경 이력, `Canvas.tsx` 캔버스.

테스트는 한글 Mermaid 예제, 중첩 그룹, 접힌 그룹의 연결 투영, 그룹 이동,
중복 이동 방지, 그룹화 토글·해제·삭제, 서브그래프 변환, 단축키의 포커스·키 반복,
복사본의 독립성, 중첩 서브그래프 탐색·입출력 연결·풀기, 안팎으로 나뉘는 분기 연결,
노출 설정의 원본 연결·복제·정리, 정렬, 저장·불러오기,
잘못된 입력을 다룹니다.
